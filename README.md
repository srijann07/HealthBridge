# HealthBridge

> **Legacy prototype.** The actively developed HealthAI implementation is maintained in [`healthai-deploy`](https://github.com/srijann07/healthai-deploy).

HealthBridge is an earlier prototype of a health-management application built while exploring the project architecture, authentication flow, database-backed features, and user-facing health workflows.

## Why this repository exists

This repository preserves the earlier project iteration and its development history. For internship reviewers, the more complete implementation is the current HealthAI repository linked above.

## Project direction

The project evolved toward a web-based system that combines:

- Patient health information and medical history
- Secure authentication and role-aware workflows
- AI-assisted health-risk screening
- Doctor review workflows
- Administrative features
- Report generation and deployment

## Current project

**HealthAI — AI-Powered Early Health Risk Detection System**  
See the current implementation and deployment work in [`healthai-deploy`](https://github.com/srijann07/healthai-deploy).
